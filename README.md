# math-problem — 모의고사 문제 도우미

수학 모의고사 PDF를 넣으면

1. **문항별 이미지로 자르고** (여러 문항이 함께 쓰는 공통 자료는 해당 문항마다 위에 붙입니다)
2. 각 문항을 **2022 개정 교육과정 단원**(과목 › 대단원 › 중단원)으로 분류하고 **AI 로 풀어 정답과 풀이 과정**을 남기며
3. 원하는 문항으로 **유사문제 / 변형문제 / 개념·접근법 연계문제**를 만들고, 따로 다시 풀어 **검산**합니다.

두 가지 형태로 씁니다. 화면과 기능은 같고, AI 와 저장 위치만 다릅니다.

| | 다운로드 버전 `mathgen.html` | claude.ai 아티팩트 |
|---|---|---|
| 여는 법 | 크롬·엣지에서 파일을 더블클릭 | claude.ai 의 아티팩트 링크 |
| AI | 설정 탭에서 고른 제공자를 API 키로 호출 (Claude, OpenAI, Google Gemini, OpenAI 호환 서버) | 페이지를 여는 사람의 Claude 계정 (처음 쓸 때 허용 여부를 묻습니다) |
| 저장 | 그 브라우저 안(IndexedDB) | 아티팩트 저장소 (다른 기기에서도 보이고, 공유받은 사람도 볼 수 있음) |
| 파일 저장 | 바로 다운로드, 폴더에 단원별 저장 | 저장할 때마다 확인 창 |
| PDF 폴더 감시 | 됨 (크롬·엣지) | 안 됨 (아티팩트는 컴퓨터 폴더에 접근할 수 없음) |

## 사용법

1. **설정** 탭(다운로드 버전)에서 AI 제공자를 고르고 API 키와 모델을 넣은 뒤 **연결 테스트**를 누릅니다.
   - Claude (Anthropic): 키는 platform.claude.com → API Keys, 모델 기본값 `claude-opus-5-5`
   - OpenAI (GPT): 키는 platform.openai.com → API keys
   - Google Gemini: 키는 aistudio.google.com → Get API key
   - OpenAI 호환 서버 (OpenRouter, 로컬 서버 등): Base URL 과 모델 이름을 직접 입력
   - **모델 목록 불러오기**로 쓸 수 있는 모델을 고를 수 있습니다. 문항 이미지를 읽어야 하므로 이미지 입력을 지원하는 모델을 고르세요.
   - 제공자마다 키와 모델을 따로 기억합니다. "이 브라우저에 키 기억"을 켜면 다음에 다시 입력하지 않아도 됩니다.
2. **① PDF 넣기** 탭에 모의고사 PDF를 끌어다 놓습니다. 페이지별로 자른 영역(빨간 상자)과 자른 문항이 보이고, 이어서 단원 분류와 풀이가 진행됩니다. 잘못 잘린 조각은 ✕ 로 지웁니다.
   - `[11~12] 그림과 같이 …` 처럼 여러 문항이 함께 쓰는 **공통 자료**(지문·그림)는 파란 점선 상자로 표시되고, 11번·12번 이미지 위에 각각 붙어 저장됩니다.
   - **같은 시험지를 다시 넣으면**(내용이 같은 파일이거나 파일 이름이 같으면) **새로 잘라 교체 / 둘 다 보관 / 취소** 중에서 고릅니다. 교체할 때 같은 번호 문항의 분류·풀이·실제 정답·만든 문제를 이어받을 수 있어서, 새로 생긴 문항만 AI 로 처리합니다.
   - **PDF 폴더 연결**(다운로드 버전, 크롬·엣지): 폴더를 연결하면 그 안의 PDF 를 10초마다 확인해 자동으로 처리하고 `done` 폴더로 옮깁니다. 같은 시험지는 이어받아 교체합니다.
   - "한 번 더 따로 풀어 정답 교차 확인"을 켜면 분류할 때와 별도로 한 번 더 풀어 두 답이 같은지 확인합니다.
3. **② 문제 저장소** 탭 왼쪽의 단원 트리(과목 › 대단원 › 중단원)로 문항을 골라 봅니다. 문항을 누르면 왼쪽에 문제 이미지, 오른쪽에 세 탭이 열립니다(‹ › 또는 ← → 키로 이전·다음 문항).
   - **정답·풀이**: AI 정답을 OMR 답안지처럼 ①~⑤ 칸(단답형은 숫자 칸)으로 보여 주고, 실제 정답 칸을 누르면 채점합니다. 풀이 과정은 번호 붙은 단계로 보여 주며, 교차 풀이가 있으면 두 풀이를 바꿔 볼 수 있습니다.
   - **분석**: 단원(직접 변경 가능), 함께 쓰이는 단원, 상대 난이도와 그 근거, 핵심 개념, 핵심 접근법, 옮겨 적은 문제
   - **유사·연계 문제**: 개수를 정해 만들고, 문제마다 "정답과 풀이 보기"로 정답·풀이 단계·검산 결과를 펼쳐 봅니다. **학습지 HTML 저장**으로 원본과 만든 문제를 한 장의 HTML로 저장합니다(인쇄하면 풀이는 숨겨집니다).
4. **③ 문항 표** 탭은 엑셀처럼 모든 문항을 한 줄씩 보여 줍니다.
   - 열: 시험, 번호, 공통 자료, 과목, 대단원, 중단원, 유형, 난이도, AI 점수, 배점, AI 정답, 교차 확인, 실제 정답, 채점, 핵심 개념, 핵심 접근법, 만든 문제 수
   - 머리글을 누르면 정렬되고, 시험·과목·상태(미분류, 교차 확인 불일치, 채점 오답 등)로 거를 수 있습니다.
   - 문항을 골라 **선택 문항 분류 / AI 풀이 / 문제 만들기**를 한꺼번에 할 수 있습니다.
   - **엑셀(.xlsx) 저장**은 '문항' 시트와 '만든 문제' 시트를 만들고, **CSV 저장**도 됩니다.
5. **단원별 ZIP 저장** / **폴더에 단원별 저장**(다운로드 버전)을 누르면 `단원별/과목/대단원/중단원/` 폴더 구조로 문항 이미지가 저장됩니다. ZIP 안의 `backup.json` 은 **백업 불러오기**로 다시 불러올 수 있습니다.

### 문제 유형

| 유형 | 설명 |
|---|---|
| 유사문제 | 구조·풀이 흐름은 같고 수치·함수·조건만 바꾼 문제 |
| 변형문제 | 같은 개념이지만 묻는 방향이나 조건을 바꿔 한 단계 다른 사고가 필요한 문제 |
| 개념연계문제 | 원본의 핵심 개념·접근법(대칭성, 그래프 개형 추론, 경우 나누기, 치환 등)을 다른 상황·단원에 적용한 문제 |

**검산:** 만든 뒤, 정답을 모르는 상태의 별도 호출로 다시 풀어 정답이 일치하는지, 조건에 모순이나 모호함이 없는지 확인합니다. 불일치한 문제는 표시되므로 사람이 한 번 더 확인하세요.

### 난이도

난이도는 저장된 문항끼리 비교한 **상대 난이도(1~5)** 입니다. AI 가 분류할 때 이미 저장된 문항 중 난이도별 기준 문항을 함께 보고 1~10점을 매기고, 이 점수(60%)와 배점(25%), 시험 안 번호 위치(15%)를 합쳐 분류된 전체 문항 중 순위로 정합니다(하위 20% = 1 … 상위 20% = 5). 문항이 늘면 자동으로 다시 계산되고, 분류된 문항이 10개 미만일 때는 AI 점수를 그대로 씁니다.

### 알아 둘 점

- 다운로드 버전의 데이터는 그 브라우저 안에 저장됩니다. 브라우저 데이터를 지우거나 다른 컴퓨터에서 열면 보이지 않으니 가끔 ZIP으로 백업하세요.
- 인터넷 연결이 필요합니다(PDF·수식·엑셀 라이브러리를 CDN에서 불러오고, AI 를 호출).
- API 키는 이 브라우저에서 고른 AI 회사로만 전송됩니다. 다른 사람과 같이 쓰는 컴퓨터라면 "기억"을 끄세요.
- 정해진 출력 형식(JSON 스키마)은 Claude 와 OpenAI 에서는 API 가 보장하고, Gemini·호환 서버·아티팩트에서는 지시문으로 요청한 뒤 결과를 검사합니다. 형식이 어긋나면 해당 문항만 실패로 표시되고 다시 시도할 수 있습니다.
- 텍스트 PDF는 자르기에 AI 를 쓰지 않습니다. 자르기 방식을 "텍스트 분석만"으로 두고 "자른 뒤 바로 단원 분류"를 끄면 AI 없이 자르기만 할 수 있습니다.

## 자르기 방식

- **텍스트 분석(기본)**: PDF의 텍스트에서 각 단의 왼쪽 끝에 있는 `1.`, `2.` … 문항 번호를 찾아 다음 번호(또는 다음 공통 자료) 직전까지 자릅니다.
  - 1단/2단은 자동으로 찾습니다. 1쪽의 큰 시험 제목처럼 가운데를 가로지르는 줄이 있어도, 제목 영역을 빼거나 문항 번호 위치를 보고 단을 나눕니다.
  - 쪽 번호(상자 포함)·저작권 문구·"확인 사항" 상자 같은 꼬리말과, 이미지 가장자리의 단 구분선·머리 줄은 뺍니다.
  - 본문 속 숫자(예: 조건 안의 "2.")는 글꼴·순서를 보고 걸러내고, 선택과목처럼 번호가 다시 23번부터 시작하는 구간도 구분합니다.
  - `[11~12]` 로 시작하는 공통 자료는 따로 잘라 해당 문항 이미지 위에 붙입니다(다른 단이나 다음 쪽에 있는 문항에도 붙습니다).
- **AI 이미지 인식**: 스캔본처럼 텍스트가 없는 페이지는 페이지 이미지를 AI 에게 보여주고 단 경계, 문항 번호, 공통 자료 위치를 받아 자릅니다. "자동"은 페이지마다 알아서 고릅니다.

자른 결과가 이상하면 페이지별 검수 이미지를 보고, 스캔본이면 "AI 이미지 인식"으로 다시 넣어 보세요.

## 2022 개정 교육과정 단원 체계

- 공통수학1: 다항식 / 방정식과 부등식 / 경우의 수 / 행렬
- 공통수학2: 도형의 방정식 / 집합과 명제 / 함수와 그래프
- 대수: 지수함수와 로그함수 / 삼각함수 / 수열
- 미적분I: 함수의 극한과 연속 / 미분 / 적분
- 확률과 통계: 경우의 수 / 확률 / 통계
- 미적분II: 수열의 극한 / 미분법 / 적분법
- 기하: 이차곡선 / 공간도형과 공간좌표 / 벡터
- 중학교 수학: 고1 3월 학력평가처럼 중학 과정을 묻는 문제용 (수와 연산 / 변화와 관계 / 도형과 측정 / 자료와 가능성)

2015 개정 시험지(예: 수학Ⅰ·Ⅱ, 선택과목 미적분)도 문제 내용을 보고 2022 개정 단원으로 옮겨 분류합니다. 예를 들어 수열의 극한은 미적분II, 다항함수의 미분은 미적분I, 지수·로그·삼각함수·수열은 대수로 들어갑니다. 단원표는 `src/app.js` 맨 위의 `TREE` 에 있습니다.

## 코드 구조

다운로드 버전과 아티팩트 버전은 같은 코드에서 만들어집니다. 고칠 때는 `src/` 를 고친 뒤 빌드하세요.

| 파일 | 내용 |
|---|---|
| `src/app.css`, `src/app.body.html`, `src/app.js` | 공통: 화면, PDF 자르기, 단원 분류·풀이·문제 생성, 상대 난이도, 문항 표, 내보내기 |
| `src/platform.standalone.js` | 다운로드 버전: AI 제공자 설정(API 키), 브라우저 저장(IndexedDB), 파일 다운로드, 폴더 감시 |
| `src/platform.artifact.js` | 아티팩트 버전: 보는 사람의 Claude 계정, 아티팩트 저장소(db·assets), downloads |
| `tools/build.py` | 두 결과물을 만드는 빌드 스크립트 (Python 3 표준 라이브러리만 사용) |
| `mathgen.html` | 빌드 결과: 다운로드 버전 |

```bash
python3 tools/build.py
```

아티팩트 버전은 KaTeX 와 pdf.js 패키지 폴더가 필요합니다 (`npm pack katex@0.16.11 pdfjs-dist@3.11.174` 로 받아 풉니다). 결과 폴더의 `mathgen-artifact.html` 을 `pdf.worker.min.js`, `cmaps.json` 과 함께 게시합니다.

```bash
python3 tools/build.py --artifact dist/artifact --katex katex/package --pdfjs pdfjs/package
```

## 테스트

Playwright 로 두 버전을 브라우저에서 테스트합니다(`tests/e2e_html.js`). AI 응답은 가짜로 대체합니다.

- 자르기 회귀 확인: `tests/fixtures/` 의 합성 시험지 PDF 세 개
  - `first.pdf`: 큰 제목이 가운데를 가로지르는 1쪽, 쪽 번호 상자, 글자보다 넓은 조건 상자
  - `group.pdf`: 공통 자료 `[11~12]` 와 그림
  - `sample.pdf`: 본문 속 가짜 번호, 선택과목처럼 23번부터 다시 시작하는 구간
- 전체 흐름: 공통 자료 자르기, 분류·교차 풀이, 정답 채점, 문제 생성·검산, 문항 표·엑셀 저장, 같은 시험지 교체·이어받기, 상대 난이도, (다운로드 버전) Claude·OpenAI·Gemini 제공자 전환

```bash
node tests/e2e_html.js standalone <libs> "$PWD/mathgen.html" "$PWD/tests/fixtures/group.pdf" <출력 폴더>
```

```bash
node tests/e2e_html.js artifact <libs> <아티팩트 빌드 폴더> "$PWD/tests/fixtures/group.pdf" <출력 폴더>
```

`<libs>` 는 `npm pack` 으로 받아 푼 katex(`package/`), pdfjs(`pdfjs/package/`), jszip(`jszip/package/`), xlsx(`xlsx/package/`) 가 있는 폴더입니다.

## 주의

실제 모의고사 PDF와 생성 결과는 저작권 문제로 저장소에 올리지 않습니다. `tests/fixtures/` 의 PDF 는 테스트용으로 직접 만든 합성 시험지입니다.
