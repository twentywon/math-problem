# math-problem — 수학 문제 도우미

수학 문제 PDF(모의고사·내신 시험지·교재·학습지)나 문제 이미지(사진·캡처)를 넣으면

1. **문항별 이미지로 자르고** (여러 문항이 함께 쓰는 공통 자료는 해당 문항마다 위에 붙입니다. 이미지는 한 장이 한 문제)
2. 각 문항을 **2022 개정 교육과정 단원**(과목 › 대단원 › 중단원)으로 분류하고 **AI 로 풀어 정답과 풀이 과정**을 남기며
3. 원하는 문항으로 **유사문제 / 변형문제 / 개념·접근법 연계문제**를 만들고, 따로 다시 풀어 **검산**합니다.

프로그램은 `mathgen.html` 파일 하나입니다. 설치할 것 없이 크롬이나 엣지에서 파일을 더블클릭해 엽니다.

같은 프로그램을 **claude.ai 아티팩트**로도 씁니다. 아티팩트에서는 API 키 없이 페이지를 연 사람의 Claude 계정으로 AI 를 쓰고, 문항은 아티팩트 저장소에 저장됩니다. 아티팩트는 `mathgen.html` 로 만들므로 기능과 화면이 같습니다([아티팩트 만들기](#아티팩트-만들기)).

## 사용법

1. **설정** 탭에서 AI 제공자를 고르고 API 키와 모델을 넣은 뒤 **연결 테스트**를 누릅니다.
   - Claude (Anthropic): 키는 platform.claude.com → API Keys, 모델 기본값 `claude-opus-5-5`
   - OpenAI (GPT): 키는 platform.openai.com → API keys
   - Google Gemini: 키는 aistudio.google.com → Get API key
   - OpenAI 호환 서버 (OpenRouter, 로컬 서버 등): Base URL 과 모델 이름을 직접 입력
   - **모델 목록 불러오기**로 쓸 수 있는 모델을 고를 수 있습니다. 문항 이미지를 읽어야 하므로 이미지 입력을 지원하는 모델을 고르세요.
   - 제공자마다 키와 모델을 따로 기억합니다. "이 브라우저에 키 기억"을 켜면 다음에 다시 입력하지 않아도 됩니다.
2. **① 문제 넣기** 탭에 PDF를 끌어다 놓습니다. 페이지별로 자른 영역(빨간 상자)과 자른 문항이 보이고, 이어서 단원 분류와 풀이가 진행됩니다. 잘못 잘린 조각은 ✕ 로 지웁니다.
   - `[11~12] 그림과 같이 …` 처럼 여러 문항이 함께 쓰는 **공통 자료**(지문·그림)는 파란 점선 상자로 표시되고, 11번·12번 이미지 위에 각각 붙어 저장됩니다.
   - **문제 이미지**(PNG·JPG·WebP 등)도 끌어다 놓거나 고를 수 있고, 캡처한 그림은 **Ctrl+V** 로 붙여넣으면 바로 들어갑니다.
     - 한 번에 넣은 이미지는 한 **출처**로 묶이고, 한 장이 한 문제입니다. 문제 번호는 파일 이름 끝의 숫자(예: `12번.png` → 12)를 쓰고, 없으면 이어서 매깁니다.
     - **넣을 곳**에서 이미 있는 출처를 고르면 그 출처에 문제가 추가됩니다(예: "내 오답 노트"에 하나씩 모으기).
     - 사진 한 장에 문제가 여러 개 있으면 "한 장에 문제가 여러 개면 AI로 나누기"를 켜세요. AI 가 문항 번호 위치를 찾아 나눕니다.
     - 이미 저장된 것과 내용이 같은 이미지는 건너뜁니다.
   - **출처**는 문항을 묶는 이름(시험지, 교재, 이미지 묶음)입니다. 넣을 때 이름을 바꿀 수 있고, 저장소와 문항 표에서 출처별로 거를 수 있습니다.
   - **같은 PDF를 다시 넣으면**(내용이 같은 파일이거나 파일 이름이 같으면) **새로 잘라 교체 / 둘 다 보관 / 취소** 중에서 고릅니다. 교체할 때 같은 번호 문항의 분류·풀이·실제 정답·만든 문제를 이어받을 수 있어서, 새로 생긴 문항만 AI 로 처리합니다.
   - **PDF 폴더 연결**(크롬·엣지): 폴더를 연결하면 그 안의 PDF 를 10초마다 확인해 자동으로 처리하고 `done` 폴더로 옮깁니다. 같은 시험지는 이어받아 교체합니다.
   - "한 번 더 따로 풀어 정답 교차 확인"을 켜면 분류할 때와 별도로 한 번 더 풀어 두 답이 같은지 확인합니다.
3. **② 문제 저장소** 탭 왼쪽의 단원 트리(과목 › 대단원 › 중단원)로 문항을 골라 봅니다. 과목이나 대단원을 누르면 아래 단원이 펼쳐지고, 다시 누르면 접힙니다(누른 단원의 문항만 보입니다). 문항을 누르면 왼쪽에 문제 이미지, 오른쪽에 세 탭이 열립니다(‹ › 또는 ← → 키로 이전·다음 문항).
   - **정답·풀이**: AI 정답을 OMR 답안지처럼 ①~⑤ 칸(단답형은 숫자 칸)으로 보여 주고, 실제 정답 칸을 누르면 채점합니다. 풀이 과정은 줄 앞 번호 없이 한 줄씩 보여 주며, 교차 풀이가 있으면 두 풀이를 바꿔 볼 수 있습니다.
   - **분석**: 단원, 함께 쓰이는 단원, 상대 난이도와 그 근거, 핵심 개념, 옮겨 적은 문제 (핵심 접근법은 정답·풀이 탭의 "분류 때 풀이"와 문항 표에서 봅니다)
   - **유사·연계 문제**: 개수를 정해 만들고, 문제마다 "정답과 풀이 보기"로 정답·풀이 단계·검산 결과를 펼쳐 봅니다. **학습지 HTML 저장**으로 원본과 만든 문제를 한 장의 HTML로 저장합니다(인쇄하면 풀이는 숨겨집니다).
     - 만든 문제마다 **텍스트 / 이미지** 보기를 바꿀 수 있습니다. 이미지는 번호·본문·그림·선택지를 시험지처럼 흰 종이에 배치한 PNG 입니다.
     - 그림이 필요한 문제는 AI 가 도형·그래프를 SVG 로 함께 그립니다(선·원·다각형·라벨만 허용하고 나머지는 지웁니다). 그림이 문제 조건과 맞는지 꼭 확인하세요.
     - **텍스트 복사**(수식은 LaTeX), **이미지 복사**(복사가 막힌 화면에서는 저장), **이미지 저장**(누르면 카드가 이미지 보기로 바뀌어 저장되는 이미지가 그 자리에 보입니다), 한 문항에서 만든 문제 전체를 **문제 이미지 모두 저장 (ZIP)** 으로 PNG·텍스트 파일 묶음으로 받을 수 있습니다.
   - **단원 옮기기**: AI 가 고른 학년·영역이 틀렸으면 두 곳에서 바꿀 수 있습니다. 직접 옮긴 단원은 "직접 지정"으로 표시되고, AI 로 다시 분류해도 바뀌지 않습니다.
     - 문항 상세 **분석** 탭: 학년·과목 → 영역(대단원) → 중단원을 차례로 고르고 **이 단원으로 옮기기**
     - **② 문제 저장소**: 문항 카드를 왼쪽 단원 트리의 중단원(또는 미분류)으로 끌어다 놓기. 접힌 과목 위에 잠시 머물면 펼쳐집니다.
   - **삭제**: 카드의 ✕ 로 문항 하나를 지웁니다(확인 창). 위쪽 **보이는 문항 삭제**는 검색·단원·난이도·출처로 거른 지금 보이는 문항만 지우고, 출처를 고르면 나오는 **출처 삭제**는 그 출처와 문항을 모두 지웁니다. 지운 문항의 분류·풀이·만든 문제도 함께 지워지고 되돌릴 수 없으니 필요하면 먼저 ZIP 으로 백업하세요.
4. **③ 문항 표** 탭은 엑셀처럼 모든 문항을 한 줄씩 보여 줍니다.
   - 열: 출처, 번호, 공통 자료, 과목, 대단원, 중단원, 유형, 난이도, AI 점수, 배점, AI 정답, 교차 확인, 실제 정답, 채점, 핵심 개념, 핵심 접근법, 만든 문제 수
   - 머리글을 누를 때마다 오름차순 → 내림차순 → 원래 순서로 바뀝니다(**정렬 원래대로** 버튼도 있습니다). 핵심 개념·접근법의 수식도 표 안에서 보입니다. 출처·과목·상태(미분류, 교차 확인 불일치, 채점 오답 등)로 거를 수 있습니다.
   - **엑셀(.xlsx) 저장**은 '문항' 시트와 '만든 문제' 시트를 만들고, **CSV 저장**도 됩니다.
5. **④ 문제 만들기** 탭은 원본 문제 없이 교육과정에서 바로 새 문제를 만듭니다.
   - **단원**: 학년·과목 → 영역(대단원) → 중단원. 중단원까지 고르면 그 단원에서, 학년·과목이나 영역까지만 고르면 그 안의 여러 단원에서 고루 만듭니다.
   - **난이도**(1~5 또는 고르게 섞어서), **유형**(저장된 문항처럼·5지선다·단답형·섞어서), **개수**(1~20), 추가 요청, 검산 여부를 고릅니다.
   - **저장된 문항의 형식을 참고합니다**: 저장소의 실제 문항에서 참고 문항 4개를 골라 글로, 그중 3개는 이미지로도 AI 에게 보여 주고, 그 범위 문항들의 유형·<보기>형·그림·배점 비율을 요약해 함께 보냅니다. AI 는 문장 투·조건 제시 방식·선택지 구성 같은 형식과 유형만 본뜨고 내용은 새로 만들도록 지시받습니다. 유형을 "저장된 문항처럼"으로 두면 5지선다·단답형 비율도 저장된 문항을 따릅니다.
   - **참고 문항 고르는 법**:
     1. 범위: 고른 중단원 → 같은 대단원 → 같은 과목 → 저장소 전체 순으로, 문항이 있는 첫 범위에서 고릅니다.
     2. 하나씩 차례로 뽑습니다. 점수가 낮은 문항이 먼저입니다: 고른 난이도와의 차이(1단계당 1점) + 오래된 출처일수록 최대 1.5점(가장 최근 출처 0점) + 고른 유형(5지선다·단답형)과 다르면 1.5점 + 그 출처에서 이미 뽑힌 문항 1개당 1점 + 0~0.3점의 무작위.
     3. 출처의 시기는 이름의 연도·월(예: "2024 고1 3월")을 먼저 보고, 없으면 넣은 날짜를 씁니다.
     4. 같은 출처에서 이미 뽑힐수록 점수가 올라가 여러 출처에서 고루 뽑히지만, 개수 제한은 없어서 출처가 하나뿐이면 그 출처에서 모두 고릅니다. 무작위 점수 때문에 같은 조건으로 다시 만들면 참고 문항이 바뀔 수 있습니다.
   - **겹치는 문제는 버립니다**: 만든 문제가 저장된 문항이나 이번에 만든 다른 문제와 거의 같으면(기호·공백을 뺀 글자 조각이 60% 이상 같으면) 저장하지 않고, 다음 요청에서 그런 문제를 만들지 말라고 알린 뒤 모자란 만큼 다시 만듭니다.
   - 난이도는 저장소에 있는 문항의 상대 난이도를 기준으로 맞춥니다.
   - 만든 문제는 **문제 저장소·문항 표와 따로 ⑤ AI 생성 문제 탭**에 저장되고, ④ 탭 아래에는 방금 만든 문제만 보입니다.
6. **⑤ AI 생성 문제** 탭은 AI 가 만든 문제를 문제 저장소처럼 **왼쪽 단원 트리**(과목 › 대단원 › 중단원, 누르면 펼치고 다시 누르면 접힘, 문제 수 표시)로 골라 봅니다. ④ 에서 만든 문제와 원본 문항의 상세 창에서 만든 유사·변형·연계 문제가 함께 모입니다.
   - 검색, 난이도·만든 곳(④ 문제 만들기 / 원본 문항)으로 거르기, 문제마다 텍스트/이미지 보기·복사·저장·삭제
   - 문제마다 **참고한 문항**이 칩으로 보이고, 누르면 그 문항의 상세 창이 열립니다. ④ 에서 만든 문제는 AI 가 형식을 주로 본떴다고 답한 참고 문항을, 답하지 않았으면 "함께 보낸 참고 문항" 전체를 적고, 원본 문항에서 만든 문제는 그 원본을 적습니다. 엑셀과 ZIP 텍스트에도 들어갑니다.
   - 보이는 문제를 **이미지 ZIP**(PNG + 정답·풀이 텍스트), **엑셀**로 저장하거나 한꺼번에 삭제
   - 백업 ZIP 에도 들어가고, **백업 불러오기**로 되살아납니다. 예전 버전에서 "AI 생성 문제" 출처로 문제 저장소에 들어간 문제는 열 때 이 탭으로 자동으로 옮겨집니다.
7. **단원별 ZIP 저장** / **폴더에 단원별 저장**(크롬·엣지)을 누르면 `단원별/과목/대단원/중단원/` 폴더 구조로 문항 이미지가 저장됩니다. ZIP 안의 `backup.json` 은 **백업 불러오기**로 다시 불러올 수 있습니다.

### 새로고침

화면(① 문제 넣기, ② 문제 저장소, ③ 문항 표, ④ 문제 만들기, ⑤ AI 생성 문제, 설정)마다 오른쪽 위에 **↻ 새로고침** 버튼이 있습니다. 그 화면을 **처음 연 것처럼 다시 조회**합니다.

- 저장소에서 내용을 새로 받아 옵니다(다운로드 버전은 브라우저 저장소를 다시 읽고, 아티팩트는 저장소 연결을 끊었다가 다시 받아 옵니다). 다른 창에서 바꾼 내용도 들어옵니다.
- 그 화면의 검색어·거르기·정렬·선택·입력 칸을 처음 상태로 되돌리고 맨 위로 올라갑니다.
  - ① 끝난 작업 칸을 치웁니다(진행 중인 작업은 그대로). ② 검색·출처·난이도·단원 선택을 풀고 단원 트리를 접습니다. ③ 검색·거르기·정렬을 풉니다. ④ 방금 만든 문제 목록을 치우고 만들기 조건을 처음 값으로(만드는 중이면 조건은 그대로). ⑤ 검색·거르기·단원 선택을 풀고 단원 트리를 접습니다. 설정은 저장하지 않은 입력을 버리고 마지막으로 저장한 값으로 되돌립니다.
- 다른 화면의 상태는 건드리지 않습니다.

### 문제 유형

| 유형 | 설명 |
|---|---|
| 유사문제 | 구조·풀이 흐름은 같고 수치·함수·조건만 바꾼 문제 |
| 변형문제 | 같은 개념이지만 묻는 방향이나 조건을 바꿔 한 단계 다른 사고가 필요한 문제 |
| 개념연계문제 | 원본의 핵심 개념·접근법(대칭성, 그래프 개형 추론, 경우 나누기, 치환 등)을 다른 상황·단원에 적용한 문제 |

**검산:** 만든 뒤, 정답을 모르는 상태의 별도 호출로 다시 풀어 정답이 일치하는지, 조건에 모순이나 모호함이 없는지 확인합니다. 불일치한 문제는 표시되므로 사람이 한 번 더 확인하세요.

### 난이도

난이도는 저장된 문항끼리 비교한 **상대 난이도(1~5)** 입니다. AI 가 분류할 때 이미 저장된 문항 중 난이도별 기준 문항을 함께 보고 1~10점을 매기고, 이 점수(60%)와 배점(25%), 출처 안 번호 위치(15%, 이미지로 넣은 문제는 쓰지 않음)를 합쳐 분류된 전체 문항 중 순위로 정합니다(하위 20% = 1 … 상위 20% = 5). 문항이 늘면 자동으로 다시 계산되고, 분류된 문항이 10개 미만일 때는 AI 점수를 그대로 씁니다.

### 알아 둘 점

- 데이터는 그 브라우저 안(IndexedDB)에 저장됩니다. 브라우저 데이터를 지우거나 다른 컴퓨터에서 열면 보이지 않으니 가끔 ZIP으로 백업하세요.
- 인터넷 연결이 필요합니다(PDF·수식·엑셀 라이브러리를 CDN에서 불러오고, AI 를 호출).
- API 키는 이 브라우저에서 고른 AI 회사로만 전송됩니다. 다른 사람과 같이 쓰는 컴퓨터라면 "기억"을 끄세요.
- 정해진 출력 형식(JSON 스키마)은 Claude 와 OpenAI 에서는 API 가 보장하고, Gemini·호환 서버에서는 지시문으로 요청한 뒤 결과를 검사합니다. 형식이 어긋나면 해당 문항만 실패로 표시되고 다시 시도할 수 있습니다.
- 텍스트 PDF는 자르기에 AI 를 쓰지 않습니다. 자르기 방식을 "텍스트 분석만"으로 두고 "자른 뒤 바로 단원 분류"를 끄면 AI 없이 자르기만 할 수 있습니다.

## 자르기 방식

- **텍스트 분석(기본)**: PDF의 텍스트에서 각 단의 왼쪽 끝에 있는 `1.`, `2.` … 문항 번호를 찾아 다음 번호(또는 다음 공통 자료) 직전까지 자릅니다.
  - 1단/2단은 자동으로 찾습니다. 1쪽의 큰 시험 제목처럼 가운데를 가로지르는 줄이 있어도, 제목 영역을 빼거나 문항 번호 위치를 보고 단을 나눕니다.
  - 쪽 번호(상자 포함)·저작권 문구·"확인 사항" 상자 같은 꼬리말과, 이미지 가장자리의 단 구분선·머리 줄은 뺍니다.
  - 본문 속 숫자(예: 조건 안의 "2.")는 글꼴·순서를 보고 걸러내고, 선택과목처럼 번호가 다시 23번부터 시작하는 구간도 구분합니다.
  - `[11~12]` 로 시작하는 공통 자료는 따로 잘라 해당 문항 이미지 위에 붙입니다(다른 단이나 다음 쪽에 있는 문항에도 붙습니다).
- **AI 이미지 인식**: 스캔본처럼 텍스트가 없는 페이지는 페이지 이미지를 AI 에게 보여주고 단 경계, 문항 번호, 공통 자료 위치를 받아 자릅니다. "자동"은 페이지마다 알아서 고릅니다.

자른 결과가 이상하면 페이지별 검수 이미지를 보고, 스캔본이면 "AI 이미지 인식"으로 다시 넣어 보세요.

## 2022 개정 교육과정 단원 체계

- 공통수학1: 다항식 / 방정식과 부등식 / 경우의 수 / 행렬
- 공통수학2: 도형의 방정식 / 집합과 명제 / 함수와 그래프
- 대수: 지수함수와 로그함수 / 삼각함수 / 수열
- 미적분I: 함수의 극한과 연속 / 미분 / 적분
- 확률과 통계: 경우의 수 / 확률 / 통계
- 미적분II: 수열의 극한 / 미분법 / 적분법
- 기하: 이차곡선 / 공간도형과 공간좌표 / 벡터
- 중학교 1·2·3학년: 고1 3월 학력평가처럼 중학 과정을 묻는 문제용. 학년마다 수와 연산 / 변화와 관계 / 도형과 측정 / 자료와 가능성
  - 1학년: 소인수분해, 정수와 유리수, 문자의 사용과 식, 일차방정식, 좌표평면과 그래프, 기본 도형과 작도, 평면도형과 입체도형, 자료의 정리와 해석
  - 2학년: 유리수와 순환소수, 식의 계산, 일차부등식, 연립일차방정식, 일차함수와 그래프, 삼각형과 사각형의 성질, 도형의 닮음, 피타고라스 정리, 경우의 수와 확률
  - 3학년: 제곱근과 실수, 다항식의 곱셈과 인수분해, 이차방정식, 이차함수와 그래프, 삼각비, 원의 성질, 산포도, 상관관계
  - 학년을 나누기 전에 "중학교 수학"으로 분류해 둔 문항은 불러올 때 해당 학년 단원으로 자동으로 옮겨집니다.

2015 개정 시험지(예: 수학Ⅰ·Ⅱ, 선택과목 미적분)도 문제 내용을 보고 2022 개정 단원으로 옮겨 분류합니다. 예를 들어 수열의 극한은 미적분II, 다항함수의 미분은 미적분I, 지수·로그·삼각함수·수열은 대수로 들어갑니다. 단원표는 `mathgen.html` 스크립트의 `TREE` 에 있습니다.

## 코드 구조

빌드 단계 없이 `mathgen.html` 을 직접 고칩니다. 아티팩트만 아래처럼 만들어 게시합니다.

| 부분 | 내용 |
|---|---|
| `<style>` | 화면 디자인 (밝은·어두운 화면 모두) |
| `<body>` | 탭, 패널, 대화 상자 뼈대 |
| `<script>` 앞부분 `PLATFORM` | AI 제공자 설정과 API 호출(Claude·OpenAI·Gemini·호환 서버), 브라우저 저장(IndexedDB), 파일 저장, 폴더 감시 |
| `<script>` 뒷부분 | PDF 자르기, 단원 분류·풀이, 상대 난이도, 문제 생성·검산, 문제 저장소·문항 표, 내보내기·가져오기 |
| `artifact/platform.js` | 아티팩트용 `PLATFORM`: AI 는 페이지를 연 사람의 Claude 계정, 저장은 아티팩트 저장소(문항 정보는 db, 이미지는 assets), 파일 저장은 downloads |
| `tools/build-artifact.js` | `mathgen.html` 의 `[PLATFORM 시작]`~`[PLATFORM 끝]` 부분을 `artifact/platform.js` 로 바꾸고 KaTeX 글꼴을 페이지에 넣어 아티팩트를 만드는 Node 스크립트 |

### 아티팩트 만들기

`mathgen.html` 을 고친 뒤 아래를 실행하면 출력 폴더에 `mathgen-artifact.html`, `pdf.worker.min.js`, `cmaps.json` 이 생깁니다. 세 파일을 함께 같은 아티팩트 주소로 다시 게시하면 반영됩니다. Node 만 있으면 되고 따로 설치할 패키지는 없습니다.

```bash
node tools/build-artifact.js <출력 폴더> <katex 패키지 폴더> <pdfjs-dist 패키지 폴더>
```

패키지 폴더는 `npm pack katex@0.16.11 pdfjs-dist@3.11.174` 로 받아 `tar -xzf` 로 푼 `package/` 폴더입니다.

## 테스트

Playwright 로 `mathgen.html` 과 아티팩트 버전을 브라우저에서 테스트합니다(`tests/e2e_html.js`). AI 응답과 아티팩트 저장소는 가짜로 대체합니다.

- 자르기 회귀 확인: `tests/fixtures/` 의 합성 시험지 PDF 세 개
  - `first.pdf`: 큰 제목이 가운데를 가로지르는 1쪽, 쪽 번호 상자, 글자보다 넓은 조건 상자
  - `group.pdf`: 공통 자료 `[11~12]` 와 그림
  - `sample.pdf`: 본문 속 가짜 번호, 선택과목처럼 23번부터 다시 시작하는 구간
- 전체 흐름: 공통 자료 자르기, 분류·교차 풀이, 정답 채점, 문제 생성·검산, 문항 표·엑셀 저장, 같은 시험지 교체·이어받기, 문제 이미지 넣기(묶기·기존 출처에 추가·같은 이미지 건너뛰기·AI 로 나누기·붙여넣기), 만든 문제의 그림 정리·시험지 모양 이미지·텍스트, 단원 접기·펴기와 옮기기, 저장소 삭제(하나·보이는 문항·출처), 문항 표에 한꺼번에 작업 없음, ⑤ AI 생성 문제 단원 트리, ④ 문제 만들기(단원 범위·난이도·유형·개수, 저장된 문항 형식 참고, 겹치는 문제 버리기, 저장소와 따로 보관함에 저장·거르기·삭제, 예전 만든 문제 옮기기), 상대 난이도, Claude·OpenAI·Gemini 제공자 전환

```bash
node tests/e2e_html.js html <libs> "$PWD/mathgen.html" "$PWD/tests/fixtures/group.pdf" <출력 폴더>
```

```bash
node tests/e2e_html.js artifact <libs> <아티팩트 출력 폴더> "$PWD/tests/fixtures/group.pdf" <출력 폴더>
```

`<libs>` 는 `npm pack katex@0.16.11 pdfjs-dist@3.11.174 jszip@3.10.1 xlsx@0.18.5 html2canvas@1.4.1` 로 받아 푼 katex(`package/`), pdfjs(`pdfjs/package/`), jszip(`jszip/package/`), xlsx(`xlsx/package/`), html2canvas(`h2c/package/`) 가 있는 폴더입니다. 확인이 하나라도 실패하면 종료 코드 1 로 끝납니다.

## 주의

실제 모의고사 PDF와 생성 결과는 저작권 문제로 저장소에 올리지 않습니다. `tests/fixtures/` 의 PDF 는 테스트용으로 직접 만든 합성 시험지입니다.
