# math-problem — 모의고사 문제 자르기 · 단원 분류 · 유사/연계 문제 생성

수학 모의고사 PDF를 넣으면

1. **문제별 이미지로 자르고** (`library/exams/<시험ID>/q01.png …`)
2. 각 문제를 **2022 개정 교육과정 단원**(과목 › 대단원 › 중단원)으로 분류해 **단원 폴더에 저장**하고 (`library/units/…`)
3. 원하는 문제에 대해 **유사문제 / 변형문제 / 개념·접근법 연계문제**를 만들고, 별도 호출로 다시 풀어 **검산**합니다 (`library/generated/<문제ID>/`)

분류·풀이·문제 생성에는 AI API를 사용합니다. `mathgen.html` 은 Claude, OpenAI, Google Gemini, OpenAI 호환 서버 중에서 고를 수 있고, Python 버전은 Claude API(`claude-opus-5-5`)를 씁니다. PDF 자르기는 텍스트가 선택되는 PDF라면 API 없이 동작합니다.

## 가장 쉬운 방법: `mathgen.html` (설치 없음)

`mathgen.html` 파일 하나만 있으면 됩니다. 크롬이나 엣지에서 파일을 더블클릭해 열고:

1. **설정** 탭에서 AI 제공자를 고르고 API 키와 모델을 넣은 뒤 **연결 테스트**를 누릅니다.
   - Claude (Anthropic): 키는 platform.claude.com → API Keys, 모델 기본값 `claude-opus-5-5`
   - OpenAI (GPT): 키는 platform.openai.com → API keys
   - Google Gemini: 키는 aistudio.google.com → Get API key
   - OpenAI 호환 서버 (OpenRouter, 로컬 서버 등): Base URL 과 모델 이름을 직접 입력
   - **모델 목록 불러오기**로 쓸 수 있는 모델을 고를 수 있습니다. 문항 이미지를 읽어야 하므로 이미지 입력을 지원하는 모델을 고르세요.
   - 제공자마다 키와 모델을 따로 기억합니다. "이 브라우저에 키 기억"을 켜면 다음에 다시 입력하지 않아도 됩니다.
2. **① PDF 넣기** 탭에 모의고사 PDF를 끌어다 놓습니다. 페이지별로 자른 영역(빨간 상자)과 자른 문항이 보이고, 이어서 단원 분류와 풀이(AI 정답)가 진행됩니다. 잘못 잘린 조각은 ✕ 로 지웁니다.
   - `[11~12] 그림과 같이 …` 처럼 여러 문항이 함께 쓰는 **공통 자료**(지문·그림)는 파란 점선 상자로 표시되고, 11번·12번 이미지 위에 각각 붙어 저장됩니다.
   - "한 번 더 따로 풀어 정답 교차 확인"을 켜면 분류할 때와 별도로 한 번 더 풀어 두 답이 같은지 확인합니다.
3. **② 문제 저장소** 탭 왼쪽의 단원 트리(과목 › 대단원 › 중단원)로 문제를 골라 봅니다. 문제를 누르면 왼쪽에 문제 이미지, 오른쪽에 세 탭이 열립니다(‹ › 또는 ← → 키로 이전·다음 문항).
   - **정답·풀이**: AI 정답을 OMR 답안지처럼 ①~⑤ 칸(단답형은 숫자 칸)으로 보여 주고, 실제 정답 칸을 누르면 채점합니다. 풀이 과정은 번호 붙은 단계로 보여 주며, 교차 풀이가 있으면 두 풀이를 바꿔 볼 수 있습니다.
   - **분석**: 단원(직접 변경 가능), 함께 쓰이는 단원, 핵심 개념, 핵심 접근법, 옮겨 적은 문제
   - **유사·연계 문제**: 개수를 정해 만들고, 문제마다 "정답과 풀이 보기"로 정답·풀이 단계·검산 결과를 펼쳐 봅니다.
   - **학습지 HTML 저장**으로 원본과 만든 문제를 한 장의 HTML로 저장합니다(인쇄하면 풀이는 숨겨집니다).
4. **③ 문항 표** 탭은 엑셀처럼 모든 문항을 한 줄씩 보여 줍니다.
   - 열: 시험, 번호, 공통 자료, 과목, 대단원, 중단원, 유형, 난이도, AI 정답, 교차 확인, 실제 정답, 채점, 핵심 개념, 핵심 접근법, 만든 문제 수
   - 머리글을 누르면 정렬되고, 시험·과목·상태(미분류, 교차 확인 불일치, 채점 오답 등)로 거를 수 있습니다.
   - **실제 정답** 칸에 정답을 적으면 AI 정답과 비교해 채점합니다.
   - 문항을 골라 **선택 문항 분류 / AI 풀이 / 문제 만들기**를 한꺼번에 할 수 있습니다.
   - **엑셀(.xlsx) 저장**은 '문항' 시트와 '만든 문제' 시트를 만들고, **CSV 저장**도 됩니다.
5. **ZIP으로 내보내기** / **폴더에 단원별 저장**(크롬·엣지)을 누르면 `units/과목/대단원/중단원/` 폴더 구조로 문제 이미지가 저장됩니다. ZIP 안의 `backup.json` 은 **백업 불러오기**로 다시 불러올 수 있습니다.

알아 둘 점

- 모든 데이터는 그 브라우저 안(IndexedDB)에 저장됩니다. 브라우저 데이터를 지우거나 다른 컴퓨터에서 열면 보이지 않으니 가끔 ZIP으로 백업하세요.
- 인터넷 연결이 필요합니다(PDF·수식·엑셀 라이브러리를 CDN에서 불러오고, AI API를 브라우저에서 직접 호출).
- API 키는 이 브라우저에서 고른 AI 회사로만 전송됩니다. 다른 사람과 같이 쓰는 컴퓨터라면 "기억"을 끄세요.
- 정해진 출력 형식(JSON 스키마)은 Claude 와 OpenAI 에서는 API 가 보장하고, Gemini·호환 서버에서는 지시문으로 요청한 뒤 결과를 검사합니다. 형식이 어긋나면 해당 문항만 실패로 표시되고 다시 시도할 수 있습니다.
- 텍스트 PDF는 자르기에 API를 쓰지 않습니다. 자르기 방식을 "텍스트 분석만"으로 두고 "자른 뒤 바로 단원 분류"를 끄면 API 없이 자르기만 할 수 있습니다.

아래는 같은 기능의 Python 명령줄 버전입니다(여러 시험지를 한꺼번에 처리하거나 자동화할 때).

## 사용법 (Python 버전)

### 1) PDF 넣고 처리하기

`inbox/` 폴더에 PDF를 넣고:

```bash
python -m mathgen inbox
```

처리된 PDF는 `inbox/done/` 으로 옮겨집니다. 계속 켜 두고 새 PDF가 들어올 때마다 처리하려면 `--watch` 를 붙입니다.

```bash
python -m mathgen inbox --watch
```

파일 하나를 바로 처리할 수도 있습니다.

```bash
python -m mathgen ingest "2026 3월 고1 모의고사.pdf" --title "2026학년도 3월 고1 학력평가"
```

### 2) 자른 결과 확인

- `library/exams/<시험ID>/_check/page_01.png` — 각 페이지에 자른 영역이 빨간 상자로 표시됩니다. 잘못 잘린 곳이 없는지 먼저 확인하세요.
- `library/index.html` — 단원별로 문제를 모아 보는 페이지입니다.

```bash
python -m mathgen list
```

```bash
python -m mathgen list --subject 대수
```

### 3) 유사·연계 문제 만들기

```bash
python -m mathgen generate 2026_3월_고1_q21
```

기본값은 유사문제 2 · 변형문제 1 · 개념연계문제 2 개입니다. 개수와 추가 요청을 바꿀 수 있습니다.

```bash
python -m mathgen generate 2026_3월_고1_q21 --similar 3 --variant 0 --concept 2 --request "난이도를 한 단계 낮춰서"
```

결과는 `library/generated/<문제ID>/generated.html` (수식 렌더링), `generated.md`, `generated.json` 에 저장됩니다. 같은 문제로 다시 생성하면 기존 결과 뒤에 이어 붙습니다.

| 유형 | 설명 |
|---|---|
| 유사문제 | 구조·풀이 흐름은 같고 수치·함수·조건만 바꾼 문제 |
| 변형문제 | 같은 개념이지만 묻는 방향이나 조건을 바꿔 한 단계 다른 사고가 필요한 문제 |
| 개념연계문제 | 원본의 핵심 개념·접근법(대칭성, 그래프 개형 추론, 경우 나누기, 치환 등)을 다른 상황·단원에 적용한 문제 |

**검산:** 생성 후, 정답을 모르는 상태의 별도 호출로 각 문제를 다시 풀어 정답이 일치하는지, 조건에 모순이나 모호함이 없는지 확인합니다. 불일치한 문제는 결과 페이지에 빨간 글씨로 표시되므로 사람이 한 번 더 확인하세요. 비용을 줄이려면 `--no-verify` 로 끌 수 있습니다.

### 그 밖의 명령

| 명령 | 하는 일 |
|---|---|
| `python -m mathgen split <pdf>` | 자르기만 (API 사용 안 함) |
| `python -m mathgen classify <시험ID 또는 문제ID>` | 다시 분류 (분류가 마음에 안 들 때) |
| `python -m mathgen classify --all` | 아직 분류 안 된 문제 모두 분류 |
| `python -m mathgen units` | 2022 개정 단원 코드표 |
| `python -m mathgen html` | `library/index.html` 다시 만들기 |

## 저장 구조

```
library/
├── index.json                         모든 문제의 메타데이터와 분류 결과
├── index.html                         단원별 둘러보기 페이지
├── exams/<시험ID>/
│   ├── source.pdf
│   ├── q01.png, q02.png, …           자른 문제 이미지 (시험지 순서)
│   └── _check/page_01.png, …         검수용 이미지
├── units/<과목>/<대단원>/<중단원>/     단원별로 분류된 문제 이미지
│   └── <시험ID>_q01.png
└── generated/<문제ID>/                생성한 문제 (html / md / json)
```

`index.json` 에는 문제마다 옮겨 적은 문제 텍스트(LaTeX), 그림 설명, 주 단원과 함께 쓰이는 단원, 핵심 개념, 핵심 접근법, 정답·풀이, 난이도(1~5)가 저장됩니다.

## 2022 개정 교육과정 단원 체계

`mathgen/curriculum.py` 에 정의되어 있습니다(`python -m mathgen units` 로 전체 보기).

- 공통수학1: 다항식 / 방정식과 부등식 / 경우의 수 / 행렬
- 공통수학2: 도형의 방정식 / 집합과 명제 / 함수와 그래프
- 대수: 지수함수와 로그함수 / 삼각함수 / 수열
- 미적분I: 함수의 극한과 연속 / 미분 / 적분
- 확률과 통계: 경우의 수 / 확률 / 통계
- 미적분II: 수열의 극한 / 미분법 / 적분법
- 기하: 이차곡선 / 공간도형과 공간좌표 / 벡터
- 중학교 수학: 고1 3월 학력평가처럼 중학 과정을 묻는 문제용 (수와 연산 / 변화와 관계 / 도형과 측정 / 자료와 가능성)

2015 개정 시험지(예: 수학Ⅰ·Ⅱ, 선택과목 미적분)도 문제 내용을 보고 2022 개정 단원으로 옮겨 분류합니다. 예를 들어 수열의 극한은 미적분II, 다항함수의 미분은 미적분I, 지수·로그·삼각함수·수열은 대수로 들어갑니다.

## 자르기 방식

- **text 모드(기본)**: PDF의 텍스트에서 각 단의 왼쪽 끝에 있는 `1.`, `2.` … 문제 번호를 찾아 다음 번호(또는 다음 공통 자료) 직전까지 자릅니다. `[11~12]` 로 시작하는 공통 자료는 따로 잘라 해당 문항 이미지 위에 붙입니다(다른 단이나 다음 쪽에 있는 문항에도 붙습니다). 단 구분(1단/2단)은 자동으로 찾고, 쪽 번호·저작권 문구·"확인 사항" 같은 꼬리말은 뺍니다. 본문 속 숫자(예: 조건 안의 "2.")는 글꼴·순서를 보고 걸러냅니다. 선택과목처럼 번호가 다시 23번부터 시작하는 구간도 구분합니다(`section` 값).
- **vision 모드**: 스캔본처럼 텍스트가 없는 페이지는 페이지 이미지를 Claude에게 보여주고 단 경계와 문제 번호 위치를 받아 자릅니다. `--mode auto`(기본)는 페이지마다 자동으로 고르며, `--mode vision` 으로 강제할 수 있습니다.

자른 결과가 이상하면 `_check` 이미지를 보고 `--mode vision` 으로 다시 시도해 보세요.

## 비용 참고

- 분류: 문제당 1회 호출 (이미지 + 단원표; 단원표는 프롬프트 캐시됨)
- 생성: 원본 1개당 1회 + 검산 문제당 1회
- 모델을 바꾸려면 `MATHGEN_MODEL` 환경변수를 설정합니다 (예: `export MATHGEN_MODEL=claude-sonnet-5-5`).
- 안전 분류기가 요청을 거절할 때를 대비해 서버측 대체 모델(fallback)을 켜 두었습니다.

## 코드 구조 (HTML·아티팩트 버전)

`mathgen.html`(다운로드 버전)과 claude.ai 아티팩트 버전은 같은 코드에서 만들어집니다. 고칠 때는 `src/` 를 고친 뒤 빌드하세요.

| 파일 | 내용 |
|---|---|
| `src/app.css`, `src/app.body.html`, `src/app.js` | 공통: 화면, PDF 자르기, 단원 분류·풀이·문제 생성, 문항 표, 내보내기 |
| `src/platform.standalone.js` | 다운로드 버전: AI 제공자 설정(API 키), 브라우저 저장(IndexedDB), 파일 다운로드 |
| `src/platform.artifact.js` | 아티팩트 버전: 보는 사람의 Claude 계정, 아티팩트 저장소(db·assets), downloads |
| `tools/build.py` | 두 결과물을 만드는 빌드 스크립트 |

```bash
python tools/build.py
```

아티팩트 버전은 KaTeX 와 pdf.js 패키지 폴더가 필요합니다 (`npm pack katex@0.16.11 pdfjs-dist@3.11.174` 로 받아 풉니다).

```bash
python tools/build.py --artifact dist/artifact --katex katex/package --pdfjs pdfjs/package
```

## 테스트

```bash
python -m pytest -q tests
```

테스트는 2단 구성의 가짜 시험지 PDF(공통 자료 `[11~12]` 가 있는 시험지, 큰 제목이 가운데를 가로지르는 1쪽 포함)를 만들어 자르기를 검증하고, Claude 호출은 가짜 클라이언트로 대체해 전체 흐름(분류 → 단원 폴더 저장 → 생성 → 검산 → HTML)을 확인합니다.

`mathgen.html` 과 아티팩트 버전은 Playwright 로 브라우저 테스트를 합니다(`tests/e2e_html.js standalone|artifact …`). Claude·OpenAI·Gemini 응답을 흉내 내 공통 자료 자르기, 분류·교차 풀이, 문항 표·채점·엑셀 저장, 일괄 문제 생성, 제공자 전환을 확인합니다. 실행 방법은 파일 맨 위 주석에 있습니다.
